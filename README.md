# alakei1 — персональный сайт

Статический сайт-визитка Python-разработчика. Хостинг: GitHub Pages.

## Структура проекта

    .
    ├── index.html              разметка страницы
    ├── .nojekyll               обязательный пустой файл для GitHub Pages
    ├── assets/
    │   └── photo.png           фото профиля (квадрат 1:1)
    ├── css/
    │   ├── base.css            переменные, фон, типографика, сетка
    │   ├── components.css      кнопки, карточки, теги, формы, тост
    │   └── sections.css        секции (nav, hero, about, ...) + адаптив
    └── js/
        ├── data/
        │   ├── config.js       личные данные: имя, контакты, цифры, партнёры
        │   ├── projects.js     список проектов
        │   └── skills.js       навыки и проценты
        ├── render.js           рендер данных в HTML
        ├── animations.js       reveal, счётчики, кольцо, полоски
        ├── ui.js               табы, фильтр, форма, копирование, тост
        ├── tilt.js             3D-эффект карточек
        └── main.js             точка входа

## Что где менять

### Личные данные — js/data/config.js

Один файл для всего личного:

- имя, ник, локация
- email, Telegram, GitHub
- ID формы Formspree
- цифры опыта (годы, проценты, количество проектов)
- список партнёров со ссылками

При изменении данных в этом файле они автоматически обновятся на сайте.

### Проекты — js/data/projects.js

Массив объектов. Чтобы добавить новый проект, скопируйте существующий и заполните поля:

    {
      title: 'Название проекта',
      description: 'Краткое описание',
      category: 'backend',                    // "backend" или "ml"
      tags: ['Python', 'FastAPI'],
      cover: { c1: '#125446', c2: '#1B6B5A' }, // цвета градиента обложки
      links: [
        { text: 'GitHub', url: 'https://...', muted: true },
      ],
    }

Категория используется в фильтре. Если добавляете новую — не забудьте добавить её в `projectCategories` там же.

### Навыки — js/data/skills.js

Массив категорий. В каждой категории — массив навыков с полем `value` (процент от 0 до 100).

Проценты и полоски обновляются автоматически, править HTML не нужно.

### Тексты «Обо мне», «Услуги» — index.html

Это статичный HTML. Ищите секции по комментариям:

    <!-- ABOUT -->
    <!-- SERVICES -->
    <!-- CONTACT -->

### Цвета — css/base.css

Все цвета в блоке `:root`:

    --accent: #125446;    основной зелёный
    --terra:  #C96F5A;    акцентный терракот
    --bg:     #112221;    фон

## Фото профиля

- Файл: `assets/photo.png`
- Формат: квадрат 1:1 (рекомендуется от 400×400)
- Регистр имени важен
- Если файл не найден — на месте фото появится буква «А»

## Форма обратной связи

Форма работает через Formspree.

1. Зарегистрируйтесь на formspree.io
2. Создайте новую форму
3. Скопируйте ID (последняя часть URL после `/f/`)
4. Вставьте его в `js/data/config.js` в поле `formspreeId`

Если ID не указан или неверный — при отправке появится уведомление с подсказкой.

## Локальный запуск

Скрипты подключены как ES-модули (`<script type="module">`). Из-за этого открытие `index.html` двойным кликом не сработает — браузер заблокирует загрузку модулей по политике CORS.

Запустите локальный сервер:

    python -m http.server 8000

или

    npx serve

Затем откройте http://localhost:8000

## Деплой на GitHub Pages

1. Создайте репозиторий. Для домена вида `username.github.io` репозиторий должен называться точно так же.
2. Загрузите все файлы и папки, кроме `README.md` (он не обязателен).
3. Обязательно создайте пустой файл `.nojekyll` в корне. Без него GitHub Pages обработает файлы через Jekyll и часть из них не загрузится.
4. Откройте Settings → Pages.
5. Source: `Deploy from a branch`.
6. Branch: `main`, папка `/ (root)`.
7. Сохраните. Через 1–2 минуты сайт будет доступен.

## Частые проблемы

**Белый экран или пустая страница**

Откройте DevTools (F12), вкладка Console. Скорее всего не загружаются модули. Проверьте, что открываете сайт по http, а не как файл.

**Фото не отображается**

Проверьте точное имя файла (`photo.png`, не `Photo.PNG`) и путь (`assets/photo.png`).

**Форма не отправляет**

Проверьте `formspreeId` в `js/data/config.js`. Он должен соответствовать реальному ID из личного кабинета Formspree.

**Ссылки на партнёров не работают**

Проверьте массив `partners` в `js/data/config.js`. Поле `url` должно начинаться с `https://`.
